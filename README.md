# Sorting-Hat-Quiz
Python project that asks users 3 questions using input and output functions. To decide which of the four houses the user belongs, the program implements conditional statements and relational operators. In addition this program displays the scoreboard and the house with the most points.

#Features
- Asks the user a few questions
- Allows the user to input a value
- Uses conditional statements and arithmetic to calculate points
  given the user's input
- Calculates house with the most points

# Technologies
- C++
- Relational operators
- Conditional statements

#How to Run
1) Download this repository
2) Ensure Python 3 is installed
3) Open a terminal in the project folder
4) Run this code
